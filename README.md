# 🐳 DeepSeek 桌面宠物「鲸鱼娘」v3

一只住在你 Windows 桌面上的鲸鱼娘。**100% 本地运行，不联网**，与你的 DeepSeek Harness（DSH）干活状态实时联动。

## 核心功能

| 功能 | 说明 |
| --- | --- |
| 🔗 干活联动 | 通过 DSH 本地 API 实时读取状态：**干活时原地转圈 + 气泡显示正在做什么**（如"正在：跑命令"），**干活期间所有移动冻结**（不散步/不甩飞/不跟鼠标），出错播报 failed 动画，**干完自动跳跃欢呼** 🎉 |
| 🎬 官方 9 态动画 | idle / waving / running / running-left / running-right / jumping / waiting / failed / review 全部接上：干活→running，调用工具→running-right，跟随鼠标→左右跑动，完成→jumping，出错→failed，提问→review |
| 🎨 多皮肤 | 鲸鱼娘（官方 9 态动画）/ 经典小鲸 🐳 / 蓝鲸 🐋 / 海豚 🐬 / 海豹 🦭 |
| 📏 四级大小 | 右键 → 大小：小 / 标准（原生分辨率）/ 大（默认）/ 特大，选择会被记住 |
| 🦘 跳跃动画 | 点她一下会跳起来（真实重力物理 + 落地压扁回弹） |
| 💨 甩飞物理 | **拖住快速甩出去**：惯性滑动 + 摩擦减速 + 屏幕四边弹性反弹（仅你主动甩才触发） |
| 🖱️ 跟随鼠标 | 右键开启后，她会追着你的鼠标跑，自动切换左右跑动动画 |
| 💬 互动气泡 | 摸头、喂小鱼干、随机闲聊、干活/完成播报 |
| 😴 睡觉模式 | 半透明 + 打盹动画，点一下唤醒 |
| 🎪 待机活动 | 空闲时自己找事做：**左右散步（到屏幕边自动停）、挥手、打哈欠、小跳、闲聊**；3 分钟没人理还会打个小盹 💤 |
| 🚶‍♂️ 巡逻模式 | 右键开启后**满屏巡逻**：上下左右直线行走覆盖整个显示器，撞到四边自动反弹，偶尔换方向；开关状态会被记住 |
| 📌 记忆 | 皮肤、大小、位置、跟随、置顶偏好实时保存到 `pet.cfg` |
| 🖥️ 多显示器 | 默认出现在鼠标所在屏幕的右下角，位置钳制覆盖全部显示器 |

## 怎么启动

双击 **`StartPet.bat`**。首次启动她会在屏幕右下角跟你打招呼。

## 干活联动原理（透明说明）

架构上把"网络/文件扫描"和"UI 动画"彻底分开：

1. 宠物启动时自动拉起一个隐藏辅助进程 `DshStateWatcher.ps1`；
2. 辅助进程每 1.5 秒调用 DSH 官方本地接口（`http://127.0.0.1:3080` 的 `session.list` / `session.history`）获取会话 `running` 状态与最近事件（工具调用等），写入状态文件；
3. DSH 服务不可达时，辅助进程自动降级为检查 `~\.dsh\sessions\` 日志文件修改时间；
4. 宠物 UI 每 1.5 秒只读一次状态文件（微秒级），**主进程永远不做任何网络请求和递归文件扫描**，动画、拖拽绝不被卡死；
5. 宠物退出或被强杀后，辅助进程检测不到父进程会自动退出，不留孤儿。

- 干活持续 ≥8 秒后停止 → 判定"干完了" → 跳跃庆祝；
- 完全本地读取，**不会上传任何内容、不联网**。

## 常见问题

- **看不到她？** 窗口很小（约 190×212，随大小档位缩放），默认在鼠标所在屏幕的右下角。
- **想换台词？** 用记事本打开 `DeepSeekPet.ps1`，找 `$script:IdleLines`、`WorkLines`、`DoneLines` 改文字即可。
- **不想联动干活状态？** 注释掉脚本里 `$script:WatchTimer.Start()` 那一行。
- **卸载？** 直接删除整个 `DeepSeekPet` 文件夹，不往系统里写任何东西。
- **开机自启？** `Win+R` → `shell:startup` → 放入 `StartPet.bat` 的快捷方式。
